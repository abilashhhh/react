  ^  - Caret
    Allows updates that do not change the leftmost non-zero digit.
    ^18.2.0 allows updates up to <19.0.0 (i.e., 18.x.x is allowed).
    ^0.2.5 allows updates up to <0.3.0 (since 0 is the first non-zero digit, minor versions are locked).
    ^0.0.5 allows only 0.0.x updates (no minor or major updates).

  ~  - Tilde
    Allows updates to the patch version but locks the minor version.
    ~18.2.0 allows updates up to <18.3.0 (i.e., 18.2.x is allowed, but 18.3.0 is not).
    ~0.2.5 allows updates up to <0.3.0 (same as above since 0.2.x is locked).
----------------------------------------------------------------------------
package.json  → Specifies dependencies.
    Defines project dependencies and scripts.
    Uses version ranges (^ or ~).
    Allows flexibility in dependency versions.

package-lock.json → Freezes exact versions.
    Locks exact dependency versions for consistency.
    Ensures all installations use the same versions.
    Automatically generated by npm.

Every package, we have will have its on package.json and package-lock.json

Transitive dependencies
    A transitive dependency is a package that your project does not directly depend on but is required by one of your direct dependencies.
    Eg: express depends on body-parser. body-parser depends on qs.
